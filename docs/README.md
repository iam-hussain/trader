what's left to do. The repo's top-level [`README.md`](../README.md) is the
quick-start; the files here are the deep cuts.

| [`GLOSSARY.md`](./GLOSSARY.md) | Trading + project jargon decoded. |

Each document is self-contained — read what you need; don't be required to
read in order.
